# Equipment

## Essential Equipment
Everything you need for a first batch.

| Item | Purpose | Notes |
|---|---|---|
| Fermenter (bucket or carboy) with lid and airlock | Holds the beer while it ferments | 25 L (6.5 gal) gives headroom for a 19 - 23 L batch |
| Sanitiser (e.g. Star San) | Kills microbes | Most important purchase |
| Cleaner (e.g. PBW or oxygen cleaner) | Removes dirt and residue | Unscented only |
| Hydrometer and test jar | Measures gravity, so you can work out alcohol | Essential for knowing fermentation is finished |
| Thermometer | Checks wort and fermentation temperature | Stick-on strip is fine for fermenters |
| Long spoon | Stirring | Stainless or food-grade plastic |
| Large pot (15 L or larger) | Boiling wort | Stainless steel recommended |
| Auto-siphon and tubing | Transferring beer without splashing | |
| Bottling bucket with spigot, wand | Bottling | |
| Bottles, caps and capper | Packaging | Use non-twist-off bottles |

## Upgrades
Buy these once you have brewed a few batches.

| Upgrade | Benefit |
|---|---|
| Immersion chiller | Cools wort fast, giving clearer beer and reducing infection risk |
| Temperature control (fridge + controller) | Biggest improvement to beer quality |
| Larger kettle and burner | Required for full-volume boils and all grain |
| Mash tun or BIAB bag | Allows [mashing](/beer/techniques/mashing) |
| Kegging system | Faster than bottling. See [Kegging](/beer/techniques/packaging/kegging) |
| Yeast starter equipment | See [Starters](/beer/techniques/fermentation/yeast-management/starters) |

## Materials to Avoid
- Aluminium for long-term wort storage
- Scratched plastic that cannot be sanitised
- Wooden spoons
- Anything scented, such as soaps and detergents
