# Tag Reference

Canonical vocabulary for frontmatter fields, so pages stay filterable (e.g. via an Obsidian Bases view) instead of accumulating one-off values.

## `difficulty` (topic pages)
- `beginner`
- `intermediate`
- `advanced`

## `beverage` (topic pages)
- `beer`
- `cider`
- `mead`
- `wine`

## `type` (recipe pages)
- `All Grain`
- `Extract`
- `Partial Mash`

## `carbonation_type` (recipe pages)
- `bottle`
- `keg`
- `forced`

## `type` (event pages)
- `club-event`
- `external-competition`

## BJCP style tags (`beer/bjcp-styles/**`)
Style pages use a freetext `## Tags` line rather than these frontmatter fields — see any existing style page for examples (strength, color, fermentation, region, etc.). Keep new tags lowercase-hyphenated and prefer an existing tag over inventing a near-duplicate.
