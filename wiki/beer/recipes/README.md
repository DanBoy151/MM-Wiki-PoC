# Beer Recipes

Member recipes live here, one page per recipe. To add one: copy [[../../housekeeping/Templates/Recipe-Template|Recipe Template]] into this folder, name it `<Style>-<Your Name>.md`, and fill it in. See [[../../housekeeping/Contributing|Contributing]] for the full walkthrough, and [[../../housekeeping/BeerXML-Mapping|BeerXML-Mapping]] if you're importing/exporting from brewing software.

If the recipe was brewed for a club event or entered into a competition, link it from the relevant page under [[../../competitions/README|competitions]] too.
