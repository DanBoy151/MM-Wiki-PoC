# Competitions

Where the club records events and results, linked to the recipes that were entered.

- [[club-events/README|Club Events]] — intra-club competitions, brew days, and socials
- [[external-competitions/README|External Competitions]] — BJCP-sanctioned or regional comps members entered individually

To add an event, copy [[../housekeeping/Templates/Event-Template|Event Template]] into the relevant folder, then have each entrant link `event:`/`placement:` back on their own recipe page (see [[../housekeeping/Contributing|Contributing]]).
