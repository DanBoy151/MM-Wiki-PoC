# Mead Styles

BJCP publishes a separate **Mead Style Guidelines** document (distinct from the Beer Style Guidelines that `beer/bjcp-styles/` is built from), covering categories like Traditional Mead, Melomel (fruit), Cyser (apple), Pyment (grape), Braggot (with malt), and Metheglin (spiced). It isn't reproduced here yet — add style pages under this folder as members need them, following the same page format as the beer style library (`## Overall Impression`, `## Aroma`, `## Appearance`, `## Flavor`, `## Mouthfeel`, `## Comments`, `## Vital Statistics`, `## Tags`).

Until then, recipes can link `style:` directly to a description in their own `## Comments`/`## Brewer's Notes` section, or to a page you add here.
