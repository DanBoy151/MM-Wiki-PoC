# Mead Recipes

Member recipes live here, one page per recipe. To add one: copy [[../../housekeeping/Templates/Recipe-Template|Recipe Template]] into this folder, name it `<Style>-<Your Name>.md`, and fill it in — list honey/adjuncts in the Fermentables table, and nutrient additions in Misc / Water Agents (leave `## Mash Steps` empty). See [[../../housekeeping/Contributing|Contributing]] for the full walkthrough.

If the recipe was brewed for a club event or entered into a competition, link it from the relevant page under [[../../competitions/README|competitions]] too.
