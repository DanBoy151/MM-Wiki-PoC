# Cider Styles

BJCP publishes a separate **Cider & Perry Style Guidelines** document (distinct from the Beer Style Guidelines that `beer/bjcp-styles/` is built from). It isn't reproduced here yet — add style pages under this folder as members need them, following the same page format as the beer style library (`## Overall Impression`, `## Aroma`, `## Appearance`, `## Flavor`, `## Mouthfeel`, `## Comments`, `## Vital Statistics`, `## Tags`).

Until then, recipes can link `style:` directly to a description in their own `## Comments`/`## Brewer's Notes` section, or to a page you add here.
