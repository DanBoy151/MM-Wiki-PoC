# Cider Recipes

Member recipes live here, one page per recipe. To add one: copy [[../../housekeeping/Templates/Recipe-Template|Recipe Template]] into this folder, name it `<Style>-<Your Name>.md`, and fill it in (leave the `## Mash Steps` table empty — it doesn't apply to cider). See [[../../housekeeping/Contributing|Contributing]] for the full walkthrough.

If the recipe was brewed for a club event or entered into a competition, link it from the relevant page under [[../../competitions/README|competitions]] too.
