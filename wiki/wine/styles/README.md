# Wine Styles

Unlike beer, mead, and cider, BJCP does not publish wine style guidelines, so there's no single reference this section is built from. Add style/varietal notes here as members need them (e.g. by grape variety or wine type), using the same page format as the beer style library where it's useful (`## Overall Impression`, `## Aroma`, `## Appearance`, `## Flavor`, `## Vital Statistics`, `## Tags`) — drop sections that don't apply.

Until then, recipes can link `style:` directly to a description in their own `## Comments`/`## Brewer's Notes` section, or to a page you add here.
